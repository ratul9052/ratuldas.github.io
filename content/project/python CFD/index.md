This project implements a suite of numerical solvers for 1D and 2D convection, diffusion, and convection–diffusion equations, including linear, nonlinear, and Burgers’ formulations. Using finite-difference methods, it explores stability, discretization, and numerical behavior across progressively complex PDEs, forming a foundational step toward solving the full Navier–Stokes equations.
